# Toan--infra
Mcp connectors skills everything that can upgrade my Claude or so 

## Skills

- `skills/video-analyzer` — dà a Claude la vista sui video via Gemini (file o URL; modalità `general` e `ads`). Ispirata a [mikefutia/claude-vision](https://github.com/mikefutia/claude-vision) (MIT). Install: `cp -r skills/video-analyzer ~/.claude/skills/`, `pip install google-genai yt-dlp`, `export GEMINI_API_KEY=...`.
